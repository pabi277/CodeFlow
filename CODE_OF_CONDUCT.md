# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in CodeFlow a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity, experience level, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

**Do:** use welcoming language, respect different viewpoints, accept constructive criticism, focus on what is best for the community, and show empathy.

**Don't:** use sexualized language, troll, insult, harass, publish others' private information, or conduct yourself in a way that would be unprofessional in a workplace.

## Enforcement

Report unacceptable behavior via a GitHub issue labeled `conduct` or by contacting the maintainers listed on the repository. Maintainers will review and respond. They may remove comments, commits, or ban contributors who violate this code.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
